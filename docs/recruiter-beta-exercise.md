# Independent recruiter beta exercise

Status: prepared; independent user sessions have not been observed.

Ask three invited recruiters to use one real job and candidate each, with permission to process the records. Do not coach the first attempt. Never record candidate names, resumes, or private notes in this report. Use tester aliases and anonymous job references.

1. Record start time and create/open the job.
2. Add a candidate and identify a useful screening question. Record time to first useful result.
3. Capture a real observation in Quick feedback. Check interpretation fidelity.
4. Review new evaluations when appropriate; explain any accepted change.
5. Edit/save/copy the submission draft. Refresh after saving and verify persistence.
6. Ask whether they would choose Ancalagon for the next candidate. Check usage after their next search rather than assuming stated intent means adoption.
